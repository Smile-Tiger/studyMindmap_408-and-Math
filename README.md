# studyMindmap — 考研数学 / 408 章节思维导图 Skill

> 把学完的一章压成一份能在 Obsidian 大纲里直接跳转的 Markdown 笔记：`#` 章 → `##` 知识点 → 加粗标签列表。
> 不画知识图谱，不用 Mermaid，不生成"点 + 箭头"的图 —— 只用井号分层。

写给正在准备考研的人：目标是**扫一眼能回忆起这章有什么**，而不是再写一遍教材。

---

## 这是什么

一个 WorkBuddy / Agent Skill。装上之后，说一句「做这一章的思维导图」，它会按固定格式产出：

- 两级标题，Obsidian 大纲里只有一层可跳节点
- 每个知识点用 `- **条件**：…` `- **结论**：…` `- **人话**：…` `- **易错**：…` 挂在列表里
- 公式内联 LaTeX，图片 `![[xxx.png]]` 嵌在对应小节下
- 每节 3~6 条，不写证明、不写教材式展开、末尾不放汇总表

**明确不做的事**（都是实测下来会拖慢复习的）：

| 不做 | 原因 |
|---|---|
| Python / Graphviz / Mermaid 画图 | 节点一多就没法看，且改一个字就要重跑脚本 |
| 三级、四级标题 | 大纲变长，跳转反而慢 |
| 末尾的「定理链」「条件对照」「易错清单」汇总块 | 复习时不会回头看，纯占篇幅 |
| 例题 | 刷题归刷题，导图归导图 |
| 长篇证明 | 需要时单独问 |

## 输出长这样

```markdown
# 微分中值定理与导数的应用

> 用途：中值定理看条件，导数应用看 $f'$、$f''$ 的符号。
> 更新：2026-11-13。

---

## ② 罗尔定理

- **条件**：$[a,b]$ 上连续、$(a,b)$ 内可导、$f(a)=f(b)$
- **结论**：$\exists\,\xi\in(a,b)$，使 $f'(\xi)=0$
- **人话**：从山脚出发，回到同样高度，路上必有一处是平的
- **易错**：三个条件缺一不可。$y=\lvert x\rvert$ 在 $[-1,1]$ 上 $f(-1)=f(1)$，但在 $0$ 处不可导，结论失效

![[罗尔定理.png]]

---
```

## 用法

直接说，不用点名 skill：

```
做这一章的思维导图
按微分中值定理那份的格式整理第 6 章
把这章沉淀一下
补充进我的导图：极值的第三充分条件……
```

动手前它只问三个问题，一次问完：

| 问题 | 为什么问 |
|---|---|
| 这次哪一章？只圈真正学过的部分 | 没学的不能进图 |
| XX 这块学过没？进不进图？ | 定理常有"学了一半"的状态 |
| 已有 `xxx.md`，替换 / 末尾续写 / 新建？ | 猜错就白改一遍 |

格式偏好（层级、公式、图片、篇幅、要不要汇总块）**不会重复问** —— 已经写死在 `SKILL.md` 里。

### 两类请求分得很开

- **「解释一下」** → 只在聊天里回答，不动文件
- **「补充进笔记」** → 才写文件，插到对应小节，不动其他部分

## 文件落在哪

| 科目 | 导图 | 图片 |
|---|---|---|
| 数学 | `考研/数学/思维导图/<章名>.md` | `考研/数学/思维导图/<知识点>图/<名>.png` |

> **注意**：这套路径是作者本地的 Obsidian 库约定，写在 `SKILL.md` 第三节。**换环境必须改**，否则会找不到库。

## 数学 / 408 标签对照

**数学**（按内容类型挑，不硬凑）

| 内容类型 | 标签顺序 |
|---|---|
| 定理 | 条件 → 结论 → 人话 → 几何 → 与 XX 的关系 → 易错 |
| 概念 | 定义 → 人话 → 易错 |
| 判定 / 性质 | 判定 → 求 XX 的步骤 → 易错 |
| 多档充分条件 | 第一 → 第二 → 第三充分条件 → 记法 |

**408**（数学那套 + 专用补充）

`定义` `人话` `要点` `流程` `对比` `计算` `复杂度` `考点` `易错`

四本书侧重不同：数据结构重存储对比与复杂度，计组重公式 + 单位 + 数值例子，操作系统重流程与调度规则，网络重分层与协议对比。

## 格式校验

交付前跑一遍，能查出标题层级超标、行首 Tab（Obsidian 会渲染成代码块）、半角引号、图片路径失效、误加的汇总块：

```bash
python scripts/check_mindmap.py "考研/数学/思维导图/微分中值定理.md"
```

输出示例：

```
文件：微分中值定理.md
行数：185
标题分布：H1×1，H2×11
图片引用：6 处
----------------------------------------
通过：结构、缩进、引号、图片引用均正常。
```

有 `[ERROR]` 时退出码为 1，可直接接进 CI 或 pre-commit。
