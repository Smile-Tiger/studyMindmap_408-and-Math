# 408 写法（四本书）

## 一、通用标签

`定义` / `人话` / `要点` / `流程` / `对比` / `计算` / `复杂度` / `考点` / `易错`

按内容挑 3~5 个，不硬凑。408 是选择题 + 大题，标注要能直接对着考法。

| 标签 | 写什么 |
|---|---|
| **定义** | 一句话，术语第一次出现要解释 |
| **人话** | 日常类比，一句封顶 |
| **要点** | 关键性质 2~3 条，一条一个事实 |
| **流程** | `1.` `2.` `3.` 有序列表，每步一行，写清触发条件与结果 |
| **对比** | 两列或三列表格，只对比容易混的维度 |
| **计算** | 公式 + 一个带单位的数值示例 |
| **复杂度** | 时间 / 空间，标明平均还是最坏、对谁而言 |
| **考点** | 选择题常见挖坑方向（「最多 / 最少」「至少」「平均」这类限定词） |
| **易错** | 错在哪、为什么错 |

## 二、四本书的侧重

### 数据结构

结构定义 → 存储方式对比 → 基本操作 + 复杂度 → 易错。

- 按主题拆文件：`树.md`、`图.md`、`排序.md`，不把整本书塞一个文件。
- 复杂度必须标明平均 / 最坏；同一操作不同存储方式要并排给。
- 易错典型：树的高度 vs 深度、完全二叉树结点编号、邻接矩阵的空间代价、稳定性。

### 计算机组成原理

计算题为主，公式 + 单位 + 一步数值示例。

- 每个公式后面跟一个代入数字的例子（CPI、Cache 命中率、浮点数表示范围、总线带宽）。
- 数值一定带单位：ns、MB、位、字节。
- 对比表优先：Cache 三种映射、指令寻址方式、中断 vs DMA、程序查询 vs 中断。

### 操作系统

机制按流程写：`1. 触发 → 2. 处理 → 3. 结果`。

- 对比表：进程 vs 线程、分页 vs 分段、死锁四个必要条件。
- 调度算法给「怎么选下一个」的一句话规则，再补优缺点。
- 页面置换、磁盘调度这类算法要写清「命中 / 缺页时各做什么」。

### 计算机网络

分层结构 + 协议对比表 + 报文关键字段。

- 每层先写「这一层解决什么问题」，不要只列协议名。
- 对比：TCP vs UDP、各层设备与作用范围、拥塞控制四阶段。
- 报文格式只记题目会问的字段（如 TCP 首部固定 20 字节、IP 首部关键字段）。

## 三、文件头

沿用数学的结构，可多一行「对应」标注教材章节：

```markdown
# 树

> 用途：二叉树的性质与遍历是选择+算法题的主战场。
> 对应：《数据结构》第 5 章。
> 更新：2026-11-13。
```

不默认加 YAML tags，除非用户要求。

## 四、禁止

- 算法完整代码实现（除非用户要求，只写思路 + 复杂度）
- 大段教材定义照抄
- 末尾汇总表、考点清单
