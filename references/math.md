# 数学章节写法

## 一、标签词表（按内容类型挑，不硬凑）

| 内容类型 | 标签顺序 |
|---|---|
| 定理 | 条件 → 结论 → 人话 → 几何 → 与 XX 的关系 → 易错 |
| 概念 | 定义 → 人话 → 易错 |
| 判定 / 性质 | 判定 → 求 XX 的步骤 → 易错 |
| 多档充分条件 | 第一充分条件 → 第二充分条件 → 第三充分条件 → 记法 |
| 方法 / 解题策略 | 单独一个不编号的 `##` 节，放在知识块之间 |

只保留用得上的标签。定理没有几何意义就不写「几何」，别为了凑齐格式硬造一行。

## 二、写法要点

1. **人话一句封顶**，用生活比喻：「山顶或谷底，那一刻一定是平的」「从山脚出发，回到同样高度，路上必有一处是平的」。
2. **易错必须配具体反例**，不写空话：
   - `y=x^3` 在 0：`f'=0` 但不是极值点（必要条件不充分）
   - `|x|` 在 0：不可导却是极值点（漏找不可导点）
   - `x^4` 在 0：`f''=0` 但不是拐点（`f''` 不变号）
3. **多档条件给参照物记法**：「找第一个不为零的导数，偶数阶像 x²（有极值），奇数阶像 x³（没有）」。
4. **递进关系单独一行**「与 XX 的关系」，只写退化方式不写证明：柯西取 `g(x)=x` 就退回拉格朗日；泰勒 `n=0` 就是拉格朗日。
5. **跨章重复内容只留一处**，另一处留链接，不复制两份。
6. **步骤类写清分界点从哪来**：定义域 → 求导 → 找 `f'=0` 和 `f'` 不存在的点 → 切开 → 逐段判号。
7. **易混对照才用表格**，且只放两列/三列。表格不等于汇总块，挂在对应知识点下是允许的。

## 三、编号

`## ①` 到 `## ⑩` 全章连续，不按半章重新起编。方法论这类过渡节不占编号：

```markdown
## ⑤ 泰勒定理
## 怎么挑定理（用法）
## ⑥ 单调性
```

## 四、公式与图片

- 结论式直接写在节点里，用 `$$...$$` 独立成行；推导和公式表链到 `[[数学笔记#小节名]]`，不搬运。
- 图片用 `![[知识点.png]]`，放在对应小节末尾、`---` 之前。图片文件名与知识点同名，存放在同级 `<知识点>图/` 文件夹。

## 五、禁止

- 定理链、条件对照表、末尾易错清单
- 证明过程、教材式背景介绍
- 例题（用户明确要求才加，只放题干）

## 六、完整样例

`/d/Develop/obsdian-bag/myStudy/考研/数学/思维导图/微分中值定理.md`

这份覆盖了：定理节、方法论节、判定节、多档充分条件、易错嵌套子项、图片嵌入、跨章合并。新章节照它的规格写。
